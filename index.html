Admin — users & access

New teammates sign in with the email + password you set here — no confirmation email is involved, and it works even when public sign-ups are switched off in Supabase. The category boxes control what each user can see and where they can create records; records without categories are visible to the whole team, and a record’s creator and assignees always see it. Admins always have full access. Which tabs a person can open — and whether they can change anything there — is set per tab with the ⚙ Tab button.
